# 开发路线图

## 版本规划

```
v0.1.0 ──→ v0.2.0 ──→ v0.3.0 ──→ v0.4.0 ──→ v0.5.0 ──→ v0.6.0 ──→ v0.7.0 ──→ v0.8.0 ──→ v0.9.0 ──→ v1.0.0
 初始化     SQLite     分类系统    活跃检测    日报生成    Obsidian    系统托盘     GUI       周报/月报    正式发布
```

## 各版本详情

### v0.1.0 — 项目初始化 + 前台窗口检测

**目标**：搭建项目骨架，实现最基本的窗口检测。

- [ ] 项目目录结构
- [ ] 基础文档（README, PRD, ARCHITECTURE）
- [ ] `window_detector.py`：GetForegroundWindow + 窗口标题 + 进程名
- [ ] 命令行循环采样并打印

**预计完成**：2026-06

### v0.2.0 — SQLite 存储

**目标**：将采样数据持久化到本地数据库。

- [ ] `database.py`：init_db, insert_activity_log
- [ ] `activity_logs` 表设计
- [ ] WAL 模式
- [ ] 按日期查询

**预计完成**：2026-06

### v0.3.0 — 软件分类系统

**目标**：基于 YAML 配置自动分类软件。

- [ ] `classifier.py`：进程名匹配 + 标题关键词匹配
- [ ] `config.example.yaml`：默认分类规则
- [ ] 浏览器场景标题优先匹配
- [ ] 默认分类兜底

**预计完成**：2026-06

### v0.4.0 — 活跃检测与有效时长

**目标**：区分主动使用和挂机。

- [ ] `activity_detector.py`：GetLastInputInfo
- [ ] 可配置空闲阈值
- [ ] `interactive_required` vs `passive_allowed`
- [ ] 有效时长字段写入数据库

**预计完成**：2026-06

### v0.5.0 — 日报生成

**目标**：每日自动/手动生成 Markdown 日报。

- [ ] `exporter.py`：Markdown 模板 + CSV 导出
- [ ] `reporter.py`：终端格式统计
- [ ] 效率评分计算
- [ ] 优化建议生成

**预计完成**：2026-07

### v0.6.0 — Obsidian 集成

**目标**：日报自动同步到 Obsidian 知识库。

- [ ] 配置 Obsidian 输出路径
- [ ] 日报文件复制到 vault
- [ ] 路径校验

**预计完成**：2026-07

### v0.7.0 — 系统托盘
