# GUI 设计

## 总体布局

```
┌─────────────────────────────────────────────────────┐
│  LifeOS Tracker          今日有效: 4h20m  ...   [暂停] [日报] │ ← 顶部栏
├──────────┬──────────────────────────────────────────┤
│          │                                          │
│  今日概览  │         QStackedWidget                  │
│  实时监控  │         7 个页面动态切换                  │
│  软件统计  │                                          │
│  分类统计  │                                          │
│  日报/周报 │                                          │
│  规则配置  │                                          │
│  设置     │                                          │
│          │                                          │
├──────────┴──────────────────────────────────────────┤
│  状态: 记录中                          最后采样: 14:30:05 │ ← 底部状态栏
└─────────────────────────────────────────────────────┘
```

- 窗口默认大小：900 × 620，最小 800 × 540
- 左侧导航栏：固定宽度 160px，深色背景
- 右侧内容区：QStackedWidget，随导航切换
- 顶部栏：标题 + 今日统计摘要 + 操作按钮
- 底部栏：录制状态 + 最后采样时间

## 页面设计

### 1. 今日概览 (Today Overview)

- **4 个数据卡片**：总使用时长、学习/工作时间、娱乐时间、挂机时间
- **效率评分**：大号数字 + 等级文字（优秀/良好/一般/需改进）
- **今日建议**：基于时间分配自动生成的优化建议
- 每 30 秒自动刷新

### 2. 实时监控 (Live Monitor)

- **上半区**：当前窗口信息
  - 进程名 + 窗口标题
  - 分类标签
  - 活跃状态指示灯
  - 空闲秒数
  - 连续使用时长
- **下半区**：最近 20 条采样记录 QTableWidget
- 每次采样信号触发时实时更新

### 3. 软件统计 (Software Stats)

- QTableWidget：软件名称 | 归类关键词 | 所属分类 | 有效时长 | 占比
- 操作按钮：导出 CSV / 导出 Markdown
- 数据来源：`database.query_date_stats(today)`

### 4. 分类统计 (Category Stats)

- 每分类一行卡片：
  - 分类名称
  - 彩色进度条（宽度按最长分类等比缩放）
  - 时长文本
- 颜色映射：AI=紫、编程=绿、阅读=蓝、娱乐=橙、空闲=灰

### 5. 报告管理 (Reports)

- 三个 Tab：日报 / 周报 / 月报
- QTableWidget 列出已生成报告（日期、文件名、大小）
- 操作按钮：生成今日日报 / 打开报告目录 / 同步到 Obsidian
- 每 60 秒自动刷新文件列表

### 6. 规则配置 (Rule Config)

- QSplitter 左右分栏（200 + 500）
- **左侧**：分类列表 QListWidget（可添加/删除）
- **右侧**：编辑区
  - 分类名称 QLineEdit
  - 进程名 QTextEdit（每行一个）
  - 标题关键词 QTextEdit（每行一个）
  - 计时规则 QComboBox
  - 操作按钮：保存修改 / 添加分类 / 删除分类
- 保存直接写入 `config.yaml`

### 7. 设置 (Settings)

- **基础设置 QGroupBox**：开机自启复选框 / 采样间隔 SpinBox / 空闲阈值 SpinBox
- **路径设置 QGroupBox**：数据库路径 / 日报输出路径 / Obsidian 输出路径（均带浏览按钮）
- **数据管理 QGroupBox**：备份数据库 / 清理 30 天前记录
- 保存按钮写入 `config.yaml`

## 系统托盘

- 右键菜单：
  - 打开主界面
  - ─────────
  - 暂停记录 / 恢复记录
  - 生成今日日报
  - 打开报告目录
  - ─────────
  - 设置
  - ─────────
  - 退出
- 双击托盘图标 → 打开主界面
- Tooltip 每 60 秒刷新：显示今日有效时长、学习/工作、娱乐、运行状态

## 窗口行为

- 关闭窗口 → 隐藏到托盘（不退出）
- 托盘退出 → 停止录制线程 → 关闭数据库 → 退出进程
- `setQuitOnLastWindowClosed(False)` → 关窗不退出应用
