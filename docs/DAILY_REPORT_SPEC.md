# DayLens 日报数据结构说明

## 文件格式

- 路径：`reports/daily/YYYY/YYYY-MM/YYYY-MM-DD.md`（如 `reports/daily/2026/2026-06/2026-06-01.md`）
- 编码：UTF-8
- 格式：Markdown

---

## 字段定义

### 1. 总览

| 字段 | 含义 | 计算方式 |
|------|------|----------|
| 总电脑使用 | 当天电脑总使用时长 | 有效时间 + 挂机/空闲时间 |
| 有效时间 | 用户活跃操作的时间 | 键盘/鼠标有操作的时段累加 |
| 挂机/空闲时间 | 电脑开着但无操作的时间 | 无 HID 输入超过 60 秒的时段 |
| 娱乐时间 | 归类为"视频娱乐"+"游戏"的有效时长 | 分类器按规则匹配 |
| 最长使用软件 | 当天使用时间最长的软件 | 按窗口标题聚合，取最大 |
| 学习/工作占比 | 有效时间中学习工作的百分比 | (AI工具+编程开发+阅读学习+创作工具) / 有效时间 × 100% |
| 娱乐占比 | 有效时间中娱乐的百分比 | 娱乐时间 / 有效时间 × 100% |

### 2. 效率评分

| 字段 | 含义 | 计算方式 |
|------|------|----------|
| 评分 | 0-100 的整数 | 学习工作占比 × 100，娱乐超 90 分钟后每 30 分钟扣 5 分（上限扣 30） |
| 等级 | 优秀/良好/一般/需改进 | ≥80 优秀, ≥60 良好, ≥40 一般, <40 需改进 |
| 数据不足 | 有效时间 < 30 分钟时 | 不评分，显示"数据不足" |

### 3. 分类统计

每个分类的有效时长（秒），当前分类：

| 分类 key | 显示名 | 典型包含 |
|-----------|--------|----------|
| ai_tools | AI工具 | ChatGPT, Claude, DeepSeek, Kimi 等 |
| coding | 编程开发 | VS Code, Cursor, Terminal, IDE 等 |
| reading | 阅读学习 | Obsidian, PDF, WPS, 文档等 |
| creative | 创作工具 | 剪映等 |
| video | 视频娱乐 | YouTube, B站, 爱奇艺, 本地播放器等 |
| gaming | 游戏 | Steam, WeGame 等 |
| social | 社交通讯 | 微信, QQ, Telegram, 企业微信等 |
| tools | 系统工具 | 远程桌面, 文件管理, 截图等 |
| browser_general | 浏览器其他 | 浏览器中未匹配到具体网站的浏览 |
| other | 其他 | 未匹配任何规则的进程 |

### 4. 软件排行

- 按窗口标题去重（去除浏览器后缀如 ` — Google Chrome`）
- 显示该标题对应的有效时长
- 最多展示 20 条
- 标题前缀符号含义：
  - `✳` = 该进程有自定义显示名映射
  - `⠂` / `⠐` = 浏览器标签页（标题经过规范化处理）

### 5. 建议

基于规则的自动建议，当前规则：
- 当日娱乐 > 90 分钟 → 提醒控制
- 连续 3 天娱乐 > 90 分钟 → 警告减少
- 有效时间 > 2 小时但学习占比 < 30% → 建议增加学习

### 6. 30分钟时间线

每天 48 个时段（00:00-00:30 到 23:30-24:00），每行含义：

| 列 | 含义 |
|----|------|
| 时间段 | 30 分钟窗口（如 14:00-14:30） |
| 主状态 | 该时段主导分类：学习/工作、娱乐、挂机、混合 |
| 有效 | 该时段内有效操作分钟数（≤30） |
| 娱乐 | 该时段内娱乐分钟数（≤有效） |
| 挂机 | 该时段内无操作分钟数（有效+挂机=30） |
| Top应用 | 该时段使用时间最长的应用 |
| 切换 | 该时段内窗口切换次数 |

主状态判定逻辑：
- 学习/工作 ≥ 20 分钟 → `学习/工作`
- 娱乐 ≥ 15 分钟 → `娱乐`
- 挂机 ≥ 20 分钟且工作 < 10 分钟 → `挂机`
- 以上都不满足 → `混合`

### 7. 今日专注时段

连续的学习/工作时段，判定条件：
- 连续的 30 分钟块中主分类为"学习/工作"或"AI工具"
- 中间允许 < 5 分钟的娱乐打断
- 累计工作 ≥ 45 分钟才算一个专注时段

### 8. 碎片化情况

| 字段 | 含义 |
|------|------|
| 窗口切换次数 | 当天所有窗口切换总次数 |
| 碎片化指数 | 0-100，越高越碎片化 |
| 评价 | 低(<25)/中等(25-50)/偏高(50-75)/严重(>75) |

碎片化指数 = min(100, 切换次数 / 有效小时数 × 10)
"混合"状态块 > 8 个时额外 +15

### 9. 一句话复盘

自动生成的摘要，包含：
- 学习集中时段（上午/下午/晚上）
- 娱乐集中时段
- 碎片化情况
- 最长专注时段

## AI 分析日报时的建议角度

1. **效率趋势**：对比多天的效率评分变化，识别效率下降/提升的日期
2. **时间结构**：分析 30 分钟时间线，找出高效时段和低效时段的时间规律
3. **专注深度**：专注时段的数量、时长、连续性，判断深度工作能力
4. **碎片化根源**：高切换时段对应什么应用？是工具切换还是娱乐打断？
5. **娱乐模式**：娱乐集中在什么时间段？是否在应该工作的时间段出现娱乐？
6. **分类结构健康度**：学习/工作占比是否合理？AI工具使用是否过度（可能意味着频繁查资料而非深度思考）？
7. **异常检测**：某天某项指标突变（如突然大量娱乐、效率骤降）
8. **改进建议**：基于时间线规律给出具体可操作的时间管理建议
