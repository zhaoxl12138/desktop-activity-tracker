# 产品需求文档 (PRD)

## 项目定位

Windows 桌面软件使用时长记录器 / 个人数字行为分析系统。

帮助用户客观了解自己的桌面时间分配，通过效率评分和优化建议引导更健康的使用习惯。

## 核心目标

### 1. 自动记录软件使用

- 每 N 秒（默认 5s）采样一次前台窗口
- 获取进程名（如 `Code.exe`）、窗口标题（如 `main.py - Visual Studio Code`）、可执行文件路径
- 在后台静默运行，不干扰用户

### 2. 智能分类

将软件按用途自动归类：

| 分类 | 示例软件 | 计时规则 |
|------|---------|---------|
| AI 工具 | ChatGPT, Claude, DeepSeek, Copilot | 需要活跃 |
| 编程开发 | VS Code, Cursor, Terminal, Codex | 需要活跃 |
| 阅读学习 | Obsidian, PDF 阅读器, Notion | 需要活跃 |
| 视频娱乐 | YouTube, B站, PotPlayer | 允许被动 |
| 浏览器其他 | 未匹配到具体分类的网页浏览 | 需要活跃 |
| 其他 | 未识别软件 | 需要活跃 |

分类规则通过 YAML 配置文件定义，用户可编辑。

### 3. 有效时长判断

- **interactive_required**（需要活跃）：在可配置的空闲阈值（默认 60s）内检测到鼠标/键盘活动，该采样周期才计入有效时间
- **passive_allowed**（允许被动）：无论是否有操作都计入有效时间（适用于视频播放等场景）

### 4. 日报生成

每日生成 Markdown 格式报告，包含：
- 按分类统计（时长 + 占比）
- 按软件统计 TOP N
- 效率评分（0-100）
- 优化建议

### 5. Obsidian 集成

- 支持配置 Obsidian vault 路径
- 日报自动复制到指定目录，便于在 Obsidian 中查看

### 6. 系统托盘

- 最小化到系统托盘，后台持续记录
- 托盘图标 Tooltip 显示今日摘要
- 右键菜单：打开主界面 / 暂停记录 / 生成日报 / 退出

### 7. GUI 可视化

PySide6 桌面界面，包含 7 个页面：
- 今日概览
- 实时监控
- 软件统计
- 分类统计
- 报告管理
- 规则配置
- 设置

### 8. 独立 EXE

PyInstaller 打包为单文件 `.exe`，无需安装 Python，在 Win10/Win11 可直接运行。

## 非目标（v1.0）

- 网络同步/云存储
- 多设备数据合并
- 团队/企业功能
- macOS/Linux 支持
- 浏览器插件
- 截图记录
- 键鼠操作内容记录
