# DeepSeek省钱模式

## 启用

在设置中心找到“DeepSeek · 省钱模式”。密钥仅存Windows凭据管理器，不要写入项目配置或聊天。保存密钥后可点击“测试连接”，这会发送固定测试文本并计入预算。开启智能增强并保存智能设置后开始判断。

默认月预算为4元（最多可设置5元）；达到预算后停止新请求，DayLens继续本地记录。界面金额使用高峰、未命中缓存单价作保守估算，最终以服务商账单为准。断网等无法确认计费的请求保留预留金额，防止重复扣费。

## 分类

- 仅未知浏览器/其他标题累计主动使用30秒后进入候选队列，每天最多30个标题。
- 一次最多5个标题；不满一批最长再等待15秒，随后请求。首次判断前的时间仍保留原分类。
- 可靠结果仅在对应标题采样时采用，相同标题以后复用缓存。涉及媒体类别的建议不会自动改变视频计时。
- “实时监控”分类旁显示AI来源，悬停查看理由；“纠正当前分类”仅针对当前应用和标题，后续记录生效。
- 排除应用和关键词对联网请求生效。标题中的网址、邮箱、长数字、路径等会被替换；仍应将机密项目名称加入排除项。
- 关闭AI影响后续记录，历史时间保持不变。人工明确指定的分类仍有效。

## 复盘

在设置中开启“自动汇总”并保存：每天当地时间23:00生成日报智能汇总，周日23:00生成周报，月末最后一天23:00生成月报。同一时点先日报、再周报、最后月报。内容直接附加到现有报告的“智能汇总”章节，原来的查看、下载及同步方式不变。

软件未运行时，下次启动补生成启用后的到期周期，不追溯启用前的历史月份。23:00生成的当日报告注明生成时刻，不表示覆盖当晚剩余时间。报告中心显示待补和未完成状态。

主题与日报共用一次请求。日报只纳入最多20个投入较多、可脱敏的工作标题；周报使用每日摘要，月报使用周摘要并补入月末未成周的日报摘要。只覆盖已有依据，不伪造完整周期分析；跨月自然周不能视为精确月统计。

每个周期最多生成一次；重复查看及原生报告刷新不会再次请求API，也不会抹掉已保存的智能章节。请求已发出但失败或结果不确定时保留状态，不自动重试。尚未发请求的预算不足等状态保留待补，继续服从每类汇总每日一次的调用上限，因此多日积压可能需要多天处理。

原生统计不依赖AI，智能结果缓存在同一数据目录的intelligence/reviews下，调度状态保存在intelligence/report_schedule.json。汇总附加操作不覆盖原报告正文。

## 数据与发布

用量、缓存及人工纠正在规范数据目录的intelligence下保存；API密钥独立存Windows凭据。没有新增使用记录数据库，也没有改写历史会话。

生产程序继续使用release/DayLens.exe。release_staging只用于构建检查，不能作为日常启动路径。
