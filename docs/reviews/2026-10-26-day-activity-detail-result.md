# 全天活动详情实施与验证

## 交付内容

- 工作节奏、娱乐时间的近7天图表均支持按日期点击，命中整列（包括零值、缺记录日期）；使用 ISO 日期，不解析短标签。今日和近30天模式不增加点击行为，原悬停提示保留。
- 一个共享的全天活动弹窗：00:00–24:00前台范围、日期切换（固定为打开时近7天）、手动刷新、按时间升序的事件明细与选中高亮。
- 默认显示原有效秒数≥300的事件；“显示全部事件”仅改变列表，标题同步变化，筛选为空时明确提示，不改变色带或计数。
- 同进程、同规范标题、同分类及版本的相邻证据可合并；缺规范标题时保守回退原始标题。间隔仅允许一个采样周期且上限2秒，不跨应用/标题/空闲或异常证据归并，不调用AI或恢复任务链。
- 单次区间查询涵盖跨午夜记录，并在同一查询中返回所选日损坏时间戳供告警；不新增首页刷新查询，不建表或迁移。未知缺口不是空闲；旧口径主动/被动值保持未知；异常、冲突、重叠证据明确降级。
- 后台单次读取，只保留最新待执行日期；工作线程只接收不可变参数和结果队列，不访问Qt控件。关闭停止投递，不等待正在读取的线程，也不影响记录线程。

## 主要源码

- `services/day_activity_service.py`：纯事件模型与只读加载；数据库 facade / stats repository 仅添加区间读接口。
- `gui/widgets/day_activity_dialog.py`：时间轴、明细与异步弹窗。
- 首页卡片日期信号、ISO日期载荷、页面转发和窗口路由，另附独立合成布局检查脚本 `tools/check_day_activity_layout.py`。

## 已知边界

会话没有精确的片段内部空闲时间戳时，只能说明“含空闲”，不能把空闲绘制到猜测的位置；跨日分配也是对现有计数的守恒展示。数据来自已落盘记录，今日最后记录时间可能略早于读取时间。无法可靠展开的证据不计入本视图可信总量，界面会告警，不代表原计时被删除或扣减。
