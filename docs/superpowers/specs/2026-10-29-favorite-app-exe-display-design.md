# 偏爱应用 `.exe` 展示清理设计

## 目标

“工作节奏”和“娱乐时间”历史卡片中的“偏爱应用”只展示适合阅读的应用名称。无论名称来自 `display_name` 还是 `process_name`，末尾的 `.exe`（大小写不敏感）都不显示。

## 边界

- 仅修改偏爱应用指标的最终展示名称。
- 不修改数据库中的进程名或显示名。
- 不修改分类规则、规则匹配、软件排行榜、报告或导出数据。
- 不改变偏爱应用的时长聚合、排序和并列处理逻辑。

## 实现

在 `_favorite_app` 选择候选名称后统一调用现有 `_strip_executable_suffix`，避免当前仅回退到 `process_name` 时才清理后缀的问题。

## 验证

- `display_name="Hades2.exe"` 显示为 `Hades2`。
- `process_name="Hades2.exe"` 的回退路径仍显示为 `Hades2`。
- 非 `.exe` 名称保持不变。
- 原始输入数据不被修改。
