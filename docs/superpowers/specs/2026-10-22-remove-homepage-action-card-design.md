# 首页“今日行动”卡片移除设计（2026-10-22）

## 目标

从“今日概览”首页完整移除“今日行动”区域，包括“今日计划”和“任务洞察”两个摘要卡片，减少首页信息重复与纵向占用。

## 范围

- 首页不再创建、布局或更新 `TodayActionCard`，移除其“查看目标”和“查看任务”跳转连接。
- 首页卡片网格在宽屏和窄屏下都由已有统计卡片自然补位，不保留空白占位。
- 停止仅为首页摘要进行的模型分发；后台任务分析、目标数据、计时算法和历史数据保持不变。
- 统计页中的“任务链”和“目标与成果”标签继续保留，相关确认、编辑、云端建议与证据查看能力不变。
- 暂不删除独立 `TodayActionCard` 类文件，以免扩大本次改动；确认无其他入口依赖后可在后续清理。

## 验收

1. 今日概览不显示“今日行动”“今日计划”或“任务洞察”摘要区域，也不存在空白占位。
2. 今日概览原有时间分布、工作节奏、娱乐时间和软件排行布局正常。
3. 统计页仍可进入“任务链”和“目标与成果”，原有数据可正常读取和操作。
4. 相关自动化测试、全量测试、`compileall` 和 GUI smoke 通过。
5. 发布目录重新构建，DayLens 重启后仅运行一个新版本实例。
