# 关键工作片段视觉层级设计

## 目标

让首页“关键工作片段”在深色界面中更醒目，并让用户一眼区分片段主题、时间、参与时长和应用来源。

## 设计

- 区块标题由 14px 普通白色升级为 15px 高权重亮蓝色。
- 片段主题由 12px 升为 13px，继续使用最高对比度正文色。
- 时间由 10px 次级灰提升为 11px 半粗亮蓝色。
- 参与时长由 11px 升为 12px，保留主蓝色强调。
- 应用列表由 10px 弱化灰提升为 11px 次级正文色，但仍低于主题和时长。
- 不改变行间距、卡片结构、卡片高度、显示条数、统计逻辑或数据库。

## 兼容与验收

- 为区块标题和行内四类标签增加稳定对象名，便于样式回归测试定位。
- 所有动态文本继续使用纯文本渲染。
- 现有 1280×720 响应式布局与五条片段容量保持不变。
