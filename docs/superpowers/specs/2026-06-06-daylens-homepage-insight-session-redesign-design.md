# DayLens 首页重设计：今日洞察 + 专注 Session

## 背景
当前首页存在两个结构性问题：

1. 右侧“时间统计”与顶部统计、时间分布重复，信息密度低。
2. “今日时间线”更像采样日志，不像用户洞察，价值不高。

本次重设计的目标是把首页从“重复统计面板”改为“洞察面板 + 专注 Session 面板”，让首页更像一个能快速回答“今天发生了什么”的产品面板。

## 目标

- 删除右侧“时间统计”卡片。
- 将“较昨日”并入“时间分布”卡片底部。
- 新增“今日洞察” 2x2 小卡片。
- 将“今日时间线”替换为“今日专注 Session”。
- 左下状态卡升级为更完整的记录状态卡。
- 保留趋势图和软件 TOP5，但整体卡片占比收紧。

## 已确认的设计取舍

- 采用 **全量洞察面板** 方案。
- “最大干扰源”先使用 **今日内会话次数最多的应用/窗口** 作为代理，不引入假的打开次数。
- 洞察规则只使用现有统计与会话数据，不接 AI，不新增模型层。

## 页面结构

### 1. 顶部摘要
保留当前顶部 4 个摘要胶囊，继续展示：

- 活跃时间
- 工作学习
- 娱乐休闲
- 社交通讯

### 2. 左侧“时间分布”
保留圆环和分类分布列表，结构收紧，职责改为：

- 展示今天的时间占比
- 展示活跃 / 离开状态
- 在卡片底部展示“较昨日”分类对比：
  - 工作学习
  - 娱乐休闲
  - 社交通讯

删除独立“时间统计”卡。

### 3. 中间“今日洞察”
新增 2x2 小卡片，四项固定：

1. 最长专注
2. 最佳状态时段
3. 最大干扰源
4. 今日建议

空状态统一文案：

- `数据积累中`
- `使用一段时间后将生成洞察`

规则要求：

- 不显示“超过多少用户”等伪数据。
- 不写 AI 分析文案，先用规则生成。
- “今日建议”控制在两行以内。

### 4. 右侧趋势图
保留趋势图，现有 `今日 / 近7天 / 近30天` 切换不变。

### 5. 底部“今日专注 Session”
替换原“今日时间线”。

布局分两层：

- 上半部分：`00:00 - 24:00` 的全天结构时间轴
- 下半部分：最近 / 重要 Session 卡片

展示规则：

- 仅显示 `effective_seconds >= 5分钟`
- 按持续时间倒序
- 首页只展示前 5 条
- 底部按钮显示 `查看全部 Session (N) ↗`

卡片信息：

- 应用名 / 窗口标题
- 起止时间
- 持续时长
- 分类标签

### 6. 左下状态卡
升级为更完整的记录状态卡，显示：

- `🟢 正在记录`
- `已记录：7时29分`
- `连续记录：第12天`
- `版本：v1.5.3`
- `最后采样：17:47:59`

要求：

- 状态颜色要明显。
- 不增加侧边栏设置入口数量。
- 信息应有成就感，但不做冗余设置项。

## 数据来源

复用 `load_today_snapshot()` 的返回值，不新增新的数据库入口：

- `distribution_sections`
- `day_comparison`
- `sessions`
- `trend.today`
- `focus_summary`
- `consecutive_days`
- `top_app_rows`

新增给“今日洞察”的规则数据建议放在服务层，避免页面层自己拼逻辑。

## 组件拆分建议

- `src/daylens/services/dashboard_service.py`
  - 增加今日洞察计算
  - 提供更适合首页使用的快照结构
- `src/daylens/gui/pages/today_overview.py`
  - 重排首页布局
  - 组合各卡片
- `src/daylens/gui/widgets/dashboard_widgets.py`
  - Session 卡片化渲染
  - 洞察小卡复用组件
- `src/daylens/gui/main_window.py`
  - 同步增强左下状态区
- `src/daylens/gui/style.py`
  - 补充洞察卡与状态卡的颜色/间距样式

## 风险点

- 1600×900 固定窗口下，新洞察卡会挤压首页空间，布局必须收紧。
- “最大干扰源”没有原始打开次数，只能使用会话次数代理，文案必须诚实。
- 24 小时时间轴和 Session 卡片如果没有做筛选，会再次退化成日志列表。
- 洞察规则必须足够轻，不要把首页刷新做重。
- 左下状态卡增加信息后，不能把侧边栏做得更拥挤。

## 测试方案

### 结构测试

- 旧“时间统计”卡不再出现在首页结构中。
- “今日洞察”四张卡存在。
- “较昨日”出现在时间分布卡底部。
- “今日专注 Session”存在。
- 左下状态卡字段存在。

### 规则测试

- 最长专注能从 fixture 中稳定选出。
- 最佳状态时段按 2 小时滑窗输出正确窗口。
- 最大干扰源按会话次数聚合正确。
- 数据不足时输出统一空状态。

### Session 测试

- 小于 5 分钟的条目不显示。
- 只保留前 5 条。
- 按持续时长倒序。
- `查看全部 Session (N) ↗` 数量正确。

### 冒烟测试

- 首页文本不再出现“时间统计”。
- 新文案 `今日洞察` / `今日专注 Session` / `正在记录` 可被检出。
- 1600×900 布局不溢出。

## 验收标准

- 首页视觉上能明显看出“洞察”而不是“重复统计”。
- Session 区块不再像逐条采样日志。
- 左下状态卡更完整，但不会破坏侧边栏密度。
- 现有趋势图、TOP5、分类统计、软件统计不回退。
