# DayLens 报告中心设计

## 目标

将“日报/周报”页面从只读文件表格改成可操作的报告中心。用户选择一份报告后，可以明确看到报告详情，并执行下载、打开和同步到 Obsidian。

## 页面结构

- 顶部保留报告生成区，统一生成日报、周报、月报。
- 中部左侧为报告列表，按日报、周报、月报切换。
- 中部右侧为选中报告详情，显示日期、类型、文件名、大小和更新时间。
- 未选中报告时，详情区显示空状态，并禁用下载、打开、同步按钮。
- 选中报告后，高亮当前行并启用操作按钮。

## 交互

- 单击报告：更新右侧详情。
- 双击报告：使用系统默认程序打开 Markdown 文件。
- 下载 Markdown：弹出系统“另存为”窗口，将选中文件复制到用户指定位置，不移动或删除原报告。
- 同步到 Obsidian：同步当前选中的报告，不再固定同步今日日报。
- 切换日报、周报、月报标签：清空旧选择，避免操作错误类型的报告。

## 数据边界

`reports_service.list_report_rows()` 返回结构化报告对象，包含：

- `label`
- `filename`
- `size_text`
- `file_path`
- `modified_text`
- `report_type`

文件定位、复制和存在性检查由服务层负责，GUI 不直接调用 exporter。

## 错误处理

- 未选择报告：按钮禁用，不弹无意义提示。
- 源文件不存在：显示“报告文件不存在”，刷新列表并清空选择。
- 下载目标与源文件相同：视为成功，不重复复制。
- 下载失败、打开失败、同步失败：显示具体错误信息。

## 测试

- 服务层返回完整路径和报告类型。
- 下载操作复制内容且不修改源文件。
- 页面初始状态无选择且操作按钮禁用。
- 选择行后详情正确、按钮启用。
- 切换标签后选择被清空。
- 双击、下载、同步均使用当前选中的文件路径。
