# DayLens 响应式 UI 与防重叠设计

## 目标

解决窗口缩放、Windows DPI 放大和较小可用区域下的控件裁切与重叠，同时保留当前 1600×900 的默认视觉布局。

## 窗口与页面容器

主窗口改为可调整大小，默认尺寸仍为 1600×900，最小尺寸设为 1100×700。主内容使用可滚动容器承载页面，页面自身不强制超出可用区域。侧边栏保留固定宽度，但导航在高度不足时允许垂直滚动。

## 固定尺寸收敛

顶部栏、主页焦点卡片和报告详情面板取消固定高度/宽度，使用最小尺寸、伸缩策略和布局 stretch。主页保留卡片的最低可读高度；规则管理页在窄宽度下通过滚动而非压缩文本解决空间不足。报告页在可用宽度不足时保留横向滚动或切换为上下布局，避免左右面板互相覆盖。

## 文本与 DPI

长标题、提示和状态文字启用 word wrap 或 elide；按钮和输入框不依赖单一固定像素宽度。测试覆盖 1600×900、1200×750 和 1100×700 三种窗口尺寸，递归检查可见控件几何区域没有超出父容器。

## 兼容性

不改变页面数据接口、导航顺序、主题配色或报告功能。窗口缩放只影响布局，不影响采集线程和页面刷新计时器。

## 验证

先增加失败的几何约束测试，再实现布局调整；运行完整 pytest、compileall、发布构建，并启动 release 版本确认单实例和快捷方式路径。
