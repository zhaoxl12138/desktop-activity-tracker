# 移除 AI 排除项设计

用户选择彻底删除设置页中的“排除应用”和“排除标题关键词”，而非仅隐藏界面。

范围：删除两个输入框及其保存逻辑；智能设置不再读取、返回或写入 `excluded_apps` / `excluded_words`；标题分类与日报证据不再根据旧字段排除标题。旧 JSON 文件保持原样直到下一次保存，届时由规范化保存去除旧字段，不迁移数据库或重写历史记录。

保留：启用开关、分类和汇总开关、月预算、密钥管理、标题长度限制与网址、邮箱、长号码、路径、密钥的脱敏。用户知晓移除自定义排除意味着以前被该规则屏蔽的普通标题以后可能进入 AI 队列。

缓存：隐私修订值固定为原空排除配置的修订值。旧空排除配置的缓存继续可用；旧非空排除配置的缓存不会跨修订用于汇总证据。失败或预算耗尽仍按现有机制降级。

验收：界面没有两项；读取和保存忽略旧字段；旧字段不再阻止标题进入候选；基础脱敏仍有效；分类、日报、预算和 GUI 回归测试通过。发布版仍使用唯一数据库路径。
