# BOSS直聘浏览器工作分类设计

## 目标

浏览器前台页面明确属于 BOSS直聘时，将该段主动参与时间计入“工作学习”。

## 方案

- 在现有 `office` 分类的浏览器标题关键词中加入 `BOSS直聘` 与 `zhipin.com`。
- 若当前唯一数据库的 `office` 自定义关键词采用 `replace` 模式，则在发布时仅向该列表追加上述两个关键词，保留其余自定义内容和模式。
- 继续使用 `interactive_required`，不因网页停留或无人操作而持续累计。
- 不使用过宽的“招聘”关键词，避免招聘新闻、视频和普通搜索结果误归工作。
- 不新增分类；首页、日报和节奏统计继续通过既有工作分类集合自动汇总。
- 不改写历史会话，只影响规则生效后的新记录。

## 验收

- Chrome 和 360ChromeX 的 BOSS直聘页面归为 `office`。
- 普通浏览器招聘相关文章仍按原规则分类。
- 分类器定向测试、全量测试、发布构建和实际运行验证通过。
