# DayLens 本地行为画像前台下线设计

## 目标

移除“本地行为画像”的用户入口、设置开关和新报告附加内容，删除没有其他调用方的画像与旧实验实现，同时保留独立的数据可信度、跨周期比较与时间守恒校验。

## 边界

- 不修改 SQLite 会话、计时算法、分类规则或历史报告文件。
- 不生成新版画像，不增加 AI 请求，也不改动既有 AI 智能汇总。
- `behavior_analysis_enabled` 继续由设置服务兼容读取和写回，旧配置不会导致加载失败；界面不再暴露该字段。
- `trusted_metrics_service.py`、报告证据指纹、数据库一致性及统计可信度逻辑保持原样。

## 实现

1. 报告中心删除“行为画像”按钮、弹窗打开方法和延迟导入；删除无调用方的 `behavior_dialog.py`。
2. 智能设置删除画像复选框；实例保留加载时读到的旧值，保存其他设置时原样写回，避免无关设置操作改写旧配置。
3. 日报、周报、月报的正常与数据不足分支均不再调用 `report_lines()`。
4. 删除仅服务于已下线功能的 `behavior_profile_service.py`、`behavior_experiment_service.py` 和专属旧测试；用新的退役回归测试覆盖入口、设置兼容、三类报告及源代码依赖清理。
5. README 删除现行功能说明，历史设计和验收文档保留为历史记录。

## 验证

- 新生成的日报、周报、月报在有数据和无数据时均不包含行为画像诊断。
- 无 API Key 时原生报告照常生成。
- 报告中心和设置中心不存在画像控件或信号。
- 画像模块没有运行时引用，核心可信度服务仍有调用和测试覆盖。
- 运行定向测试、全量 pytest、compileall、GUI smoke 和隔离发布构建。
