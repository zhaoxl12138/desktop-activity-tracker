# DayLens V1.6 任务链设计

## 范围和保护边界

V1.6 只新增可关闭的任务候选、任务级切换关联、人工纠错与可选云端建议。原始会话、分类、参与/被动/空闲秒数、旧工作片段和“明显中断”统计不变。不得迁移 SQLite 或改写历史会话。V1.7～V2.0 不在本期实施。

## 既有能力与数据流

`query_sessions_for_dates` 已提供有日期索引的一次性会话读取；新任务查询补齐 `switch_reason` 并保持只读。`dashboard_service.build_work_episode_rows` 的参与时长取值可复用，但其时间邻近分组不是任务身份。`build_interruption_analysis` 保持旧口径；新任务事件另算、另命名。`trusted_metrics_service` 和会话异常校验负责数据健康门控。`AppPaths.intelligence_dir` 是唯一派生状态目录。DeepSeek 请求、Windows 凭据、月预算与基础标题脱敏均复用现有服务。

会话读取 → 校验与去重 → 本地候选和任务事件 → 人工决定覆盖 → 稳定展示模型 → GUI。云端建议只接受本地已提交的候选/证据 ID；用户逐批预览实际脱敏载荷并确认后，后台再次检查开关、隐私版本、密钥、日限额和预算，再发送。模型结果严格校验，只能作为建议，不能生成秒数或覆盖人工决定。

## 关联与时间语义

只使用 `attention-v1` 有效会话参与秒数构建可比较任务总量；旧版本或异常记录显示为证据不足，不混算。会话按起止时间及稳定 ID 排序并去重，每条会话至多归属一个任务。3 分钟是候选相邻窗口，5 分钟是插入/返回观察窗口，都不参与原始计量。同应用同主题可形成候选；跨应用必须有可解释的共同标题词或人工确认，单凭时间相邻只给待确认。无数据连续性、跨日、锁屏和未知社交用途不能强行归因。插入经过时间不称为有效分心时间；返回只表示观察窗口内可证实的相同任务 ID。

## 状态、并发和回退

候选与证据从规范数据库按需重建，不另存原始标题；人工决定以版本化派生 JSON 单独保存，只包含任务名称、会话 ID、操作及修订号。写入使用进程/文件锁、原子替换和恢复日志；后台结果必须匹配读时修订号，否则丢弃并重算。候选 ID 由日期、起始会话 ID 与算法版本确定；人工归属以显式会话 ID 为准。云端预算在现有预算文件的请求记录增加可选幂等键，旧记录仍可读取；重复或不确定请求不再次发送。派生状态损坏时停用新功能并保留文件，原生记录与报表继续运行。关闭两个新开关即可回退；无需数据库回滚。

## 界面与验证

设置中心的本地分析和云端建议默认均关。首页新增紧凑“任务洞察”，统计页增加“任务链”标签，不新增左侧导航。显示本地统计/AI 建议/待确认及原始依据。定向测试覆盖守恒、跨应用证据、未知、不重复、人工并发/撤销、隐私预览、预算幂等及所有离线降级；每阶段全量测试、`compileall`、GUI smoke，在隔离路径执行发布 smoke。实测结果写入 `docs/reviews/`。
