# DayLens 报告批量下载设计

## 目标

在报告中心支持同一报告类型下多选报告，并将选中的 Markdown 文件批量复制到用户选择的目录。

## 交互

- 表格支持 `Ctrl` 和 `Shift` 多选整行。
- 选择一份时，保持现有详情和单文件下载、打开、同步功能。
- 选择多份时，详情标题显示“已选择 N 份报告”，并展示合计大小。
- 下载按钮显示“批量下载（N）”。
- 打开和同步按钮在多选时禁用，避免含义不明确。
- 批量下载使用目录选择器，文件保持原文件名。

## 文件冲突

- 如果目标目录已有同名文件，不覆盖。
- 自动生成 `文件名 (1).md`、`文件名 (2).md`。
- 每个源文件独立处理，一个文件失败不影响其他文件。

## 结果反馈

完成后显示：

- 成功数量
- 自动重命名数量
- 失败数量
- 目标目录

## 服务边界

服务层新增批量复制方法，负责目标命名、复制和结果汇总。GUI 只负责收集当前选中报告和选择目标目录。
