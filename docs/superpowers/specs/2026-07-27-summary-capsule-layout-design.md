# 首页顶部统计卡片布局设计

## 目标

改善首页顶部“活跃时间、工作学习、娱乐休闲、社交通讯”四项统计的可读性，保留四列横向结构和现有深色视觉风格，避免长时间文本挤压相邻项目。

## 方案

- 每项改为垂直布局：图标、标题、数值依次排列并居中。
- 四列继续使用自适应网格，列间距和卡片内边距增加。
- 数值使用固定的最小高度，确保“1时23分”和“50秒”等不同长度垂直对齐。
- 小窗口仍由现有响应式逻辑切换为两行两列，不改变导航和数据绑定。

## 验收

- 四项标签和 key 保持不变。
- 1600×900、1366×768、1100×700 下无横向重叠。
- 主题切换后布局保持，数值更新不改变卡片高度。
- 现有首页测试全部通过，并新增卡片布局方向和对齐方式回归测试。
