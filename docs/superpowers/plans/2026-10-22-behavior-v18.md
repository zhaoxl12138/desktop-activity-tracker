# V1.8 本地行为画像与实验

本期在报告中心和原生日报、周报、月报中呈现，不增加首页卡片。复用现有可信会话校验、分类集合、任务链重建及规范 intelligence 目录。

1. 聚合截至所选日期前一天的完整 7/14/30 天；缺失日期不是零。每次读取一次会话集合。本期严格要求整个对照范围每日有可信记录、计量与分类版本单一且相同；记录覆盖不代表全天覆盖。
2. 展示工作/娱乐参与及被动娱乐、按会话开始小时归组的投入分布、候选任务插入与连续工作片段。没有精确输入事件，时段分布明确是会话开始时段近似，不推断认知状态。
3. 对照窗口前后半段的日均投入与最长连续片段；同日内会话有重叠、无 ID、坏记录、版本缺失或变更时拒绝趋势。任务插入由既有确定规则重建，始终标为候选，避免把它当成真实干扰成本。
4. 设置中心新增默认关闭的本地画像开关。本期本地生成、离线可用、无新网络请求或费用；云端语言润色不进入本期必需路径。
5. 报告中心提供画像与一周实验弹窗。实验建议为每天留一段30分钟免打扰工作；用户主动接受后，次日起观察7个完整日，以前7个完整日为基线。指标为每工作小时的候选插入次数，同时显示原始次数和工作时长。保留基线证据摘要；基线变化、版本不匹配或缺数据时不出效果结论。用户可停止实验。
6. 有界派生JSON保存实验，原子写入且使用文件锁；只保存摘要和证据摘要哈希，不保存窗口标题。历史数据库与既有报告不自动改写。
7. 验证正常/缺失/异常/版本混用/重复/跨时段数据、实验主动接受与边界日期、关闭无读取、报告降级、GUI；测试完成后重建并重启。
