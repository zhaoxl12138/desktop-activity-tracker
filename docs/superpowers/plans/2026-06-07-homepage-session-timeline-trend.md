# 模块一：今日关键 Session（Top 3）

## 设计目标

替换当前卡片式 Session 展示。

当前多个横向卡片信息密度低，占用空间大，阅读效率差。

改为：

```text
今日关键 Session（Top 3）
```

采用表格列表形式展示。

---

## 布局

位于：

```text
今日专注时间轴
下方
```

宽度与时间轴保持一致。

高度控制在：

```text
180~220px
```

避免占据过多首页空间。

---

## 显示字段

每条 Session 显示：

```text
排名
软件图标
软件名称
分类
开始时间
结束时间
持续时长
```

示例：

🥇 爱奇艺（生活大爆炸）

```text
分类：娱乐休闲
开始：12:21
结束：12:38
时长：16分钟
```

🥈 腾讯视频

```text
分类：娱乐休闲
开始：15:45
结束：15:56
时长：11分钟
```

🥉 Codex

```text
分类：工作学习
开始：20:10
结束：20:20
时长：10分钟
```

---

## 排序规则

按 Session 持续时间倒序：

```text
持续时间最长
排第一

持续时间第二
排第二

持续时间第三
排第三
```

仅显示 Top3。

底部显示：

```text
查看全部 Session (N)
```

点击跳转完整 Session 页面。

---

## 视觉风格

参考：

```text
GitHub Activity
WakaTime Dashboard
JetBrains Productivity
```

避免：

```text
内容平台式卡片墙
```

风格应偏：

```text
数据分析
效率工具
专业仪表盘
```

# 模块二：时间趋势（分钟）

## 设计目标

展示一天内不同时间段的活跃趋势。

帮助用户快速发现：

```text
什么时候最专注
什么时候效率最高
什么时候进入娱乐状态
```

---

## 布局

位于首页右侧。

标题：

```text
时间趋势（分钟）
```

右上角保留：

```text
今天
近7天
近30天
```

切换按钮。

---

## 图表规则

X轴：

```text
0:00
2:00
4:00
...
24:00
```

Y轴：

```text
分钟数
```

---

## 曲线

显示两条曲线：

### 工作学习

颜色：

```text
绿色
```

表示：

```text
每小时工作学习时长
```

---

### 娱乐休闲

颜色：

```text
橙色
```

表示：

```text
每小时娱乐休闲时长
```

---

## 数据处理

不要显示秒级波动。

采用：

```text
按小时聚合
```

例如：

```text
13:00~14:00

工作学习：
42分钟

娱乐休闲：
5分钟
```

绘制成趋势线。

---

## 视觉优化

不要使用大量散点。

采用：

```text
平滑折线
半透明面积填充
```

效果类似：

```text
Apple Screen Time
RescueTime
WakaTime
```

---

## Tooltip

鼠标悬停显示：

```text
时间段

工作学习：
42分钟

娱乐休闲：
5分钟

活跃占比：
89%
```

---

## 空数据状态

当天数据不足时显示：

```text
📊 数据积累中

记录满30分钟后开始生成趋势图
```

不要显示一堆接近 0 的无意义折线。

---

目标效果：

```text
时间轴 = 看一天发生了什么

今日关键 Session = 看最重要的3段时间

时间趋势 = 看效率变化曲线
```

三个模块形成完整闭环，而不是重复展示同一份数据。
