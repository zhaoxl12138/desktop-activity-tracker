# DayLens 阶段 C：首页与导航重构执行计划

## 目标

在不改变分类、计时、播放检测和历史数据的前提下，压缩全局顶部、合并统计入口，并让首页按内容宽度在双列与单列之间稳定切换。

## 任务 1：共享视觉组件

- 新增 `PageHeader`、`CardHeader`、`MetricCell`、`DurationLabel`、`StatusBadge`、`EmptyState`、`ErrorState`。
- 所有动态文字使用纯文本；正文不低于 12px，核心值不低于 16px。
- 用共享指标单元替换工作节奏和娱乐记录底部的重复实现。

## 任务 2：紧凑顶部与导航

- 导航调整为：今日概览、统计、分类管理、报告中心、设置；保留“实时监控”诊断入口。
- 新增统计容器页，复用现有软件统计和分类统计实例，不重复查询或重建页面。
- 顶部仅保留页面标题/日期、一个“有效活动”指标、记录状态和两个操作按钮。
- 宽屏顶部不超过 112px，紧凑窗口允许轻微换行但不生成 2×2 指标墙。

## 任务 3：首页响应式布局

- 内容宽度 >=1150：约 60/40 双列。
- 850–1149：紧凑双列。
- <850：单列，顺序为时间分布、工作节奏、娱乐时间、工作切换/片段、Top5。
- 首页卡片均按内容高度布局，移除工作卡内部的强制拉伸空白。
- 侧栏宽屏 176px，紧凑窗口 64px，只显示简短导航文字；页面允许垂直滚动。

## 任务 4：状态和内容层级

- 记录状态统一为：记录中、已暂停、正在保存、记录异常、待恢复。
- 刷新失败保留上一份快照，并显示最近更新时间与简短失败提示。
- “工作干扰分析”改为“工作切换”，避免把每次离开工作都定性为干扰。
- Top5 支持点击跳转到统计页的软件标签。
- 首页诗词默认关闭，在设置中提供显式开关。

## 验证

- 定向 Qt 测试覆盖导航、顶部结构、三档布局、复用统计页、状态文案和设置持久化。
- 全量测试、`compileall`、GUI smoke、1280×720 与 1600×900 离屏渲染。
- 构建后执行发布版 smoke，再安全替换唯一运行路径并确认数据库仍为原路径。
