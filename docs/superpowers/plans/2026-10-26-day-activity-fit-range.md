# 分类横轴自动适配活动时段

用户已确认：只裁去首尾没有活动的空白，保留中间空闲与缺口的真实长度，不增加框选或缩放操作。

## 实施边界

- 仅修改分类图的显示范围和刻度；数据读取、全天摘要、分类、明细筛选及计时不变。
- 以当天首末**非空闲、有效秒数>0**的可靠事件前台范围为边界，向外取整到半小时。如09:42–12:40展示09:30–13:00。含空闲会话不能猜测内部活动结束位置。
- 单个短事件至少获得半小时显示范围；无有效活动（包括全空闲、全异常）保留当日参照并明确暂无有效活动。
- 保留内部空闲/无记录/异常的原位置，不拼接或压缩。视图外的事件仍保留在全天数据和“显示全部事件”中。
- 刻度按宽度/跨度自适应15分钟、30分钟、1小时；完整长日或窄屏可稀疏标签以避免重叠，首末刻度始终可读。
- 图标题显示实际范围，坐标映射、色块、状态背景、悬停和点击均共用同一范围。
