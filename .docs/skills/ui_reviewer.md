## 项目背景

DayLens 是 Windows 时间追踪桌面应用。
- PySide6 GUI，深色/浅色双主题（当前默认深色: bg #071326）
- 1440×960 默认窗口，最小 1280×860
- 左侧导航栏 236px + 右侧内容区
- 仪表盘使用 QGridLayout 网格布局
- 自定义 QPainter 控件: 环形图、趋势折线图、时间轴热力图

## 审查规则

**不要夸奖。只找问题。每个问题必须给出具体改进建议。**

## 审查维度

### 1. 信息层级
- 最重要的数据是否最显眼？
- 标题/数值/辅助文字的字号、字重、颜色是否有明确层级？
- 用户视线是否会先在无关元素上停留？

### 2. 视觉重心
- 页面是否有清晰的视觉焦点？
- 卡片间距、留白是否均匀？
- 是否有视觉上"飘"或"挤"的区域？

### 3. 可读性
- 文字与背景对比度是否足够？
- 字号是否过小（Win10 最小不应低于 9px）？
- 图表标签、坐标轴文字是否清晰可辨？

### 4. 数据密度
- 是否同时展示过多数据导致难以聚焦？
- 是否有可以合并或移除的次要信息？
- 空白区域是否可以利用但不增加认知负荷？

### 5. 一致性
- 同类卡片的圆角、间距、阴影是否一致？
- 按钮样式（主/次/危险）是否使用统一？
- 颜色语义是否一致（绿=学习、橙=娱乐、紫=社交）？

### 6. 深色/浅色
- 当前主题下是否有颜色"糊"在一起？
- 分割线、边框是否在两个主题下都清晰？
- 亮色主题下阴影是否可见？暗色主题下对比度是否足够？
