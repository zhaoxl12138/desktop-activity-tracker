# DayLens — 看清你的时间流向

> 1 秒级精度的 Windows 桌面时间追踪。自动归类、智能挂机检测、一键导出日报。

## 为什么你需要 DayLens？

每天在电脑前坐 8 小时，但你清楚时间花在哪了吗？DayLens 静默运行在系统托盘，自动记录每个窗口的使用时长，帮你回答三个问题：

- **今天干了什么？** — 编程 3h、开会 1.5h、刷视频 40min，一目了然
- **效率怎么样？** — 办公占比、专注时段、碎片化指数，量化你的工作状态
- **这周有进步吗？** — 周报/月报趋势对比，明天是否比今天更专注

## 核心亮点

| 特性 | 说明 |
|------|------|
| **1 秒精度采样** | 前台窗口切换不遗漏，会话边界精确到秒 |
| **智能挂机检测** | 光标 + 键盘 + 窗口三重校验，挂机确认后回溯修正有效时间 |
| **音频感知** | 检测进程是否在播放声音，暂停/静音的视频不计入娱乐时长 |
| **幻影输入过滤** | 自动屏蔽虚拟 HID 设备产生的虚假活跃信号 |
| **专注时段识别** | 自动标记 >= 45 分钟无娱乐中断的连续工作块 |
| **Markdown 日报** | 一键生成含时间线表格的日报，自动同步 Obsidian vault |
| **隐私优先** | 全部数据本地 SQLite 存储，不上传任何信息 |

## 快速开始

**下载即用**（Windows 10/11）：
从 [Releases](https://github.com/your-repo/daylens/releases) 下载最新 `DayLens_vX.X.X.zip`，解压后双击 `DayLens.exe`。

**开发者运行**：
```bash
pip install PySide6 pyyaml pycaw comtypes pynput
python -m daylens
```

**命令行模式**：
```bash
python -m daylens today              # 今日统计
python -m daylens export --format md # 导出日报
python -m daylens weekly             # 周报
python -m daylens monthly            # 月报
```

## 功能页面

| 页面 | 做什么 |
|------|--------|
| **今日概览** | 活跃时长胶囊 + 环形分类分布 + 专注时间轴 + 时间线 + 小时趋势图 + Top 5 应用 |
| **实时监控** | 当前窗口信息、分类、活跃状态 + 最近 50 条记录 |
| **软件/分类统计** | 按软件/类别维度查看时长占比，支持 CSV/Markdown 导出 |
| **日报/周报** | 生成含会话时间线的 Markdown 报告，一键同步 Obsidian |
| **目标管理** | 自定义分类规则：进程名、标题关键字、计时策略 |
| **设置中心** | 采样间隔、空闲阈值、数据库/报告路径、开机自启 |

## 系统托盘

- 关闭窗口 → 最小化到托盘，后台持续记录
- 左键托盘图标 → 打开主界面
- 右键菜单 → 暂停记录 / 退出
- 悬停 → 今日有效时长 + 办公/娱乐时长

## 分类体系

内置 11 个分类，400+ 软件自动识别：

AI 工具 · 编程开发 · 办公工作 · 阅读学习 · 设计创作 · 视频娱乐 · 音乐播客 · 社交通讯 · 金融投资 · 电商购物 · 游戏 · 远程办公 · 系统工具 · 浏览器

支持自定义分类规则和计时策略（`interactive_required` / `passive_allowed`）。
