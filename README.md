# DayLens — 看清你的时间流向

> 追踪桌面窗口，自动归类生成日报。本地存储，隐私无忧。

## 下载

从 [Releases](https://github.com/your-repo/daylens/releases) 下载 `DayLens_vX.X.X.zip`，解压后双击 `DayLens.exe` 即可运行。首次启动自动扫描本机已安装软件并加载分类。

系统要求：Windows 10/11，无需安装任何依赖。

## 功能

- **1 秒精度采样** — 窗口切换不遗漏，会话边界精确到秒
- **智能挂机检测** — 光标 + 键盘 + 窗口三重校验，挂机确认后自动回溯修正有效时长
- **音频感知** — 暂停/静音的视频不计入娱乐时间
- **幻影输入过滤** — 屏蔽虚拟 HID 设备产生的虚假活跃信号
- **专注时段识别** — 自动标记 ≥ 45 分钟无娱乐中断的连续工作块
- **Markdown 日报** — 含完整时间线表格，一键同步 Obsidian
- **14 个分类 400+ 软件** — 自动归类，支持自定义规则

## 界面

| 页面 | 功能 |
|------|------|
| **今日概览** | 活跃时长 + 分类分布环形图 + 专注时间轴 + 今日时间线 + 趋势图 + Top 5 |
| **实时监控** | 当前窗口、分类、活跃状态 |
| **软件/分类统计** | 时长占比排行，支持 CSV/Markdown 导出 |
| **日报/周报/月报** | Markdown 报告，一键同步 Obsidian |

## 托盘

关闭窗口即最小化到托盘继续记录。左键打开主界面，右键暂停/退出，悬停查看今日摘要。
